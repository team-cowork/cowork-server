# 알림

## 발송 경로

알림은 두 경로로 보냅니다.

| 경로 | 대상 | 비고 |
|---|---|---|
| SSE (`GET /notifications/stream`) | 웹에 접속 중인 사용자 | 30초마다 heartbeat 전송 |
| FCM 푸시 | 웹에 접속하지 않은 사용자의 등록 기기 | `FCM_CREDENTIALS_PATH`가 없으면 발송하지 않음 |

SSE로 전달한 사용자에게는 푸시를 보내지 않습니다.

## 알림 종류

| 종류 | 발생 시점 | 수신자 |
|---|---|---|
| `TEAM_INVITED` | 팀에 초대됨 | 초대받은 사용자 |
| `PROJECT_MEMBER_ADDED` | 프로젝트에 추가됨 | 추가된 사용자 (스스로 참여한 경우 제외) |
| `CHAT_MESSAGE` | 채널에 메시지가 올라옴 | 채널을 읽을 수 있는 사용자 (보낸 사람 제외) |
| `CHAT_MENTION` | 메시지에서 멘션됨 | 멘션된 사용자 |

## 수신하지 않는 경우

- 채널 알림 설정을 끈 사용자
- 계정 상태가 방해 금지(`DO_NOT_DISTURB`)인 사용자

## 기기 토큰

- 앱은 로그인 후 `POST /notifications/tokens`로 FCM 토큰을 등록합니다.
- 다른 사용자가 등록한 토큰이면 새 사용자에게 옮깁니다. 기기 하나에 한 사용자만 연결됩니다.
- FCM이 유효하지 않다고 응답한 토큰은 발송 직후 삭제합니다.
- 로그아웃할 때는 `DELETE /notifications/tokens/{token}`으로 토큰을 지웁니다.
