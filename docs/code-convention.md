# 코드 작성 규칙

## 패키지

도메인 패키지 아래에 계층별 패키지를 둔다.

```
com.cowork.team
├── controller   HTTP 요청과 응답 변환만 담당
├── service      비즈니스 규칙, 트랜잭션 경계
├── repository   Spring Data JPA 리포지토리
├── domain       엔티티와 값 타입
├── dto          요청·응답 DTO
└── event        도메인 이벤트
```

## 계층 책임

- 컨트롤러는 요청을 검증하고 서비스 결과를 그대로 돌려준다. 비즈니스 분기는 두지 않는다.
- 서비스는 엔티티를 DTO로 바꾸어 반환한다. 엔티티를 컨트롤러 밖으로 내보내지 않는다.
- 다른 도메인의 데이터가 필요하면 그 도메인의 서비스나 권한 검사 컴포넌트를 호출한다. 다른 도메인의 리포지토리를 직접 쓰지 않는다.
- 도메인 간 후처리(삭제 정리, 알림)는 애플리케이션 이벤트로 연결한다.

## 트랜잭션

- 조회 메서드에는 `@Transactional(readOnly = true)`를 붙인다.
- 외부 API 호출(DataGSM, FCM, S3 업로드 URL 발급)은 가능한 한 트랜잭션 밖에서 한다.
- 커밋 이후에 해야 하는 작업(실시간 전송, 알림)은 `@TransactionalEventListener`로 처리한다.

## 예외

- `BusinessException(HttpStatus, message)`만 던진다. 예외 하위 클래스는 만들지 않는다.
- 메시지는 사용자에게 그대로 보여 줄 수 있는 한국어 문장으로 쓴다.
