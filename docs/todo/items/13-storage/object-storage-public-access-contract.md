## 결정 배경

팀 아이콘의 공개 읽기는 제품 정책으로 허용한다. 채팅 첨부는 권한 회수 즉시 이미 발급한 링크까지
무효화할 필요는 없으며, 짧은 유효기간 동안의 접근을 허용한다는 사용자 결정에 따라 처리한다.
이 허용 범위를 즉시 회수 보장으로 확대해 해석하지 않는다.

기존 객체·참조의 보존과 이관은 이번 전환의 필수 조건으로 두지 않는다.
