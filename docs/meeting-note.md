# 회의록 채널

## 템플릿

- 채널마다 템플릿을 여러 개 만들 수 있고, 그중 하나만 활성화한다. 첫 템플릿은 바로 활성화된다.
- 템플릿은 섹션 목록으로 이루어진다. 섹션은 최대 30개까지 둘 수 있다.
- 사용 중인 템플릿은 삭제할 수 없다. 다른 템플릿을 먼저 활성화한다.

| 섹션 유형 | 값 형식 |
|---|---|
| `TEXT` | 문자열 |
| `MARKDOWN` | 마크다운 문자열 |
| `DATE` | `YYYY-MM-DD` |
| `DATETIME` | ISO-8601 시각 |
| `USER_LIST` | 팀 멤버 ID 배열 |

## 회의록 작성

- 회의록은 활성 템플릿을 기준으로 작성한다. 요청의 `values`는 섹션 ID를 키로 하는 객체다.
- 필수 섹션이 비어 있거나, 형식이 틀리거나, 템플릿에 없는 섹션 ID가 있으면 거부한다.
- `USER_LIST`에는 팀 멤버만 넣을 수 있다.
- 저장된 회의록은 작성 당시의 섹션 제목과 값을 함께 보관하므로, 나중에 템플릿을 바꿔도 내용이 바뀌지 않는다.
