# 계정 공유 채널

팀이 함께 쓰는 외부 서비스 계정(GitHub 조직 봇, 공용 Notion 계정 등)을 등록하고 필요할 때 자격 증명을 복사한다.

## 자격 증명 보관

- 자격 증명은 AES-256-GCM으로 암호화해 저장한다. 키는 `CREDENTIAL_ENCRYPTION_KEY`(Base64, 32바이트)로 주입한다.
- 목록과 상세 조회 응답에는 자격 증명을 넣지 않는다. 복사 API를 호출할 때만 복호화해서 돌려준다.
- 복사할 때마다 누가 언제 복사했는지 이력을 남기고, 상세 조회에서 최근 20건을 보여준다.

## OAuth 연결

GitHub, Google처럼 OAuth를 지원하는 서비스는 비밀번호 대신 OAuth로 연결한다.

1. 클라이언트가 `GET /channels/{channelId}/accounts/oauth/authorize/{provider}`로 인증 URL을 받는다.
2. 서버는 채널, 사용자, 서비스를 담은 state를 서명해서 URL에 넣는다. state는 10분 동안 유효하다.
3. 콜백에서 state를 검증하고 받은 액세스 토큰을 암호화해 공유 계정으로 저장한다.

OAuth로 연결한 계정의 자격 증명은 사용자가 직접 바꿀 수 없다.

## 키 교체

암호화 키를 바꾸면 기존 자격 증명을 읽을 수 없다. 키를 교체할 때는 공유 계정을 다시 등록하도록 팀에 안내한다.
