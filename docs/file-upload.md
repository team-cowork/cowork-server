# 파일 업로드

파일은 서버를 거치지 않고 S3(로컬은 MinIO)에 직접 올립니다.

1. 클라이언트가 업로드 URL 발급 API를 호출합니다. 요청에는 콘텐츠 타입과 파일 크기를 담습니다.
2. 서버는 크기와 형식을 검사하고, 10분 동안 유효한 presigned PUT URL과 객체 키를 돌려줍니다.
3. 클라이언트가 presigned URL로 파일을 `PUT` 합니다.
4. 클라이언트가 객체 키로 확정 API를 호출하면 서버가 실제 업로드 여부와 크기를 확인하고 저장합니다.

## 객체 키 규칙

| 용도 | 키 형식 | 최대 크기 |
|---|---|---|
| 프로필 이미지 | `profiles/{userId}/{uuid}.{ext}` | 5MB |
| 팀 아이콘 | `teams/icons/{userId}/{uuid}.{ext}` | 5MB |
| 채팅 첨부파일 | `chat/{channelId}/{userId}/{uuid}/{파일 이름}` | 50MB |

- 이미지는 PNG, JPEG, WEBP, GIF만 허용합니다.
- 확정 API는 요청한 사용자의 경로로 시작하는 키만 받습니다. 다른 사용자의 객체 키를 확정할 수 없습니다.
- 첨부파일 이름에서 경로와 허용하지 않는 문자는 `_`로 바꿉니다. 한글은 그대로 둡니다.
