개인정보처리방침

team.cowork(이하 “운영자”)는 「개인정보 보호법」에 따라 cowork 협업 서비스와 소개 사이트에서 처리하는 개인정보의 항목, 목적, 보유기간 및 이용자의 권리 행사 방법을 다음과 같이 안내합니다.

1. 처리 목적과 개인정보 항목

이용자가 직접 입력하거나 업로드한 정보, DataGSM과 연동 서비스에서 제공받는 정보, 서비스 이용 중 생성되는 정보를 처리합니다. 계정 인증과 이용자가 요청한 협업 기능에 필요한 정보는 「개인정보 보호법」 제15조제1항제4호의 계약 체결·이행을 근거로 처리합니다. 선택 프로필 정보의 수집·이용은 같은 항 제1호에 따른 별도 동의를 근거로 합니다.

  • 필수 — 로그인 및 회원 관리: DataGSM 사용자·학생 식별자, 이름, 이메일, 학생 역할과 인증·권한 정보를 처리합니다. 본인 계정과 학생 이용 자격을 확인하고, 회원을 구분하며, 서비스 관련 안내에 사용합니다. 로그인 후에도 DataGSM의 변경 알림을 받아 해당 정보를 갱신합니다. DataGSM 계정의 비밀번호는 cowork가 수집하지 않습니다.
  • 선택 — 프로필 보완: 성별, 학년·반·번호, 전공·전문 분야, GitHub 계정, 닉네임, 프로필 이미지, 소개, 협업 역할 및 상태 메시지를 처리합니다. 이용자가 선택한 자기소개와 협업자 식별에 사용하며, 수집·이용에 동의한 항목만 입력받거나 DataGSM에서 제공받아 갱신합니다. 성별은 서비스 이용 자격이나 권한을 판단하는 데 사용하지 않습니다.
  • 협업 기능 제공: 팀·채널 참여 정보와 권한, 메시지·댓글·반응·멘션, 업로드한 파일과 파일명·크기·유형, 업무·로드맵 내용·담당자 및 작성·수정 이력을 처리합니다.
  • 음성·영상 회의와 라이브: 회의·채널·팀 식별자, 참여자·진행자 식별자, 시작·종료·입장·퇴장 시각, 실시간 음성·영상·화면 공유 데이터를 처리합니다. 운영자가 제공하는 회의 기능은 미디어를 실시간 중계하며 자동 녹음·녹화 기능은 제공하지 않습니다. 참여 이력은 미디어와 구분하여 보관합니다.
  • GitHub 연동: 연동한 계정·저장소의 식별 정보, 이슈, Pull Request, 댓글 및 연동 권한 정보를 처리합니다.
  • 공유 계정 관리: 이용자가 등록한 외부 서비스 이름, 계정명·이메일 등의 식별 정보, 비밀번호·토큰 등의 인증정보, 연결한 채널, 등록자 및 등록·수정 시각을 처리합니다. 인증정보를 복사하면 복사한 이용자·공유 계정의 식별자와 복사 시각을 기록합니다. 외부 인증으로 계정을 연결하는 경우에는 계정 식별자를 저장하며, 인증 과정에서 받은 접근 토큰은 이 공유 계정 기록에 저장하지 않습니다.
  • 알림 제공: 계정·팀·채널별 알림 설정, 방해금지 시간·시간대, Firebase 기기 설치 식별자, 기기 플랫폼, 알림 제목·본문·수신 계정 식별자·이벤트 식별자·관련 콘텐츠 정보와 전송 결과를 처리합니다.
  • 이용 환경 설정: 테마, 언어, 날짜·시간 표시 형식, 시간대, 메시지 표시·입력 방식 및 이메일 수신 설정을 처리합니다. 수신 설정값을 보관하는 것만으로 광고성 정보 수신에 동의한 것으로 보지 않습니다.
  • 로그인 상태 유지: 계정 식별자, 이메일, 권한, 인증 토큰의 해시값과 만료 시각, 접속 상태 및 클라이언트가 전달한 기기 정보를 처리합니다.
  • 운영 및 문의 대응: 서비스 요청·접속·오류 기록, 이용자가 문의 시 제공한 이메일과 문의 내용을 처리합니다.
  • 소개 사이트의 팀·개발 성과 안내: 팀원의 이름, 기수, 담당 역할, GitHub 계정과 공개 프로필 이미지를 표시합니다. 공개 저장소의 커밋·Pull Request 및 작성자 식별 정보를 조회하여 개발 성과를 집계합니다. 커밋 작성자의 이메일은 집계 과정에서 조회할 수 있으나 소개 사이트에 이메일 목록으로 게시하지 않습니다.

필수 인증정보 없이는 가입과 로그인 서비스를 제공할 수 없습니다. 프로필 보완, 외부 서비스 연결, 공유 계정 등록, 회의 참여 및 푸시 알림은 이용자가 선택하는 기능이며, 사용하지 않아도 나머지 기본 서비스를 이용할 수 있습니다. 선택정보 수집·이용과 다른 이용자에게의 프로필 공개 동의는 구분하여 받으며, 선택 동의를 거부하거나 철회했다는 이유로 기본 서비스 이용을 제한하지 않습니다.

문의 정보는 요청한 상담과 권리 행사 처리에 사용합니다. 팀원의 소개 정보는 별도 동의한 항목과 공개 범위에서 게시합니다. 이 방침의 열람이나 서비스 약관에 대한 동의만으로 선택정보 처리·제3자 제공·국외이전에 동의한 것으로 보지 않습니다.

2. 보유기간과 파기

개인정보는 처리 목적에 필요한 기간 동안 보유하며, 목적이 달성되거나 보유기간이 끝나면 지체 없이 파기하는 것을 원칙으로 합니다. 법령에 따른 보존 의무가 있는 경우에는 해당 근거와 기간에 따라 별도로 보관합니다.

  • 회원 정보와 개인 설정: 서비스 이용계약이 유지되는 동안 보관합니다. 이메일로 탈퇴를 요청하면 본인 확인 후 계정, 개인 설정, 연결된 로그인 세션·알림 기기 정보 및 개인을 식별할 수 있는 회의 참여 이력을 지체 없이 삭제합니다. 선택정보는 동의 철회 시에도 해당 처리 목적이 끝난 것으로 보아 삭제합니다.
  • 공유 콘텐츠: 메시지, 댓글, 업무, 회의 기록과 첨부파일 등은 해당 팀·채널의 협업 기록에 필요한 동안 보관합니다. 탈퇴 시 작성자 표시만 바꾸는 데 그치지 않고 본문·첨부파일에 포함된 탈퇴자의 개인정보도 검토하여 삭제하거나 개인을 식별할 수 없도록 처리한 뒤 공동 기록을 유지합니다. 익명화가 어려운 부분은 삭제합니다.
  • 문의 내역: 문의자 이메일·이름, 문의 내용과 첨부파일은 처리 결과 확인과 후속 문의 대응을 위해 처리 완료일부터 1년 동안 보관한 뒤 삭제합니다. 관계 법령상 보존 사유가 있는 경우에는 그 사유와 기간을 구분하여 관리합니다.
  • 로그인 세션: 접근 토큰의 유효기간은 발급 후 30분이며, 서버의 갱신 토큰 정보는 발급·갱신 후 최대 90일 동안 유지합니다. 갱신 토큰이 교체되거나 해당 세션에서 로그아웃하면 기존 토큰 정보를 삭제하며, 만료된 세션은 주기적으로 정리합니다. 브라우저에 저장되는 인증정보의 보유기간은 제6항에서 안내합니다.
  • 확정되지 않은 임시 업로드 파일: 업로드 후 1일이 지나면 자동 삭제 대상이 됩니다. 프로필·팀 이미지와 채팅 첨부파일의 임시 저장 공간에 적용되며, 등록을 완료한 파일의 보유기간과는 다릅니다.
  • 알림 전송 처리 기록: 성공·취소·영구 실패 등으로 처리가 끝난 기록은 마지막 변경 시점부터 7일 후 순차 삭제합니다. 아직 전송·재처리 중인 기록은 처리가 끝날 때까지 유지합니다.
  • 공유 계정 및 인증정보 복사 기록: 해당 공유 계정이 유지되는 동안 보관하며, 공유 계정 또는 그 계정이 속한 채널을 삭제하면 함께 삭제합니다. 외부 서비스에 이미 발급된 비밀번호·토큰 자체를 폐기하거나 다른 이용자가 복사한 정보를 회수하는 절차는 아닙니다.
  • 중앙 수집 운영 로그: 요청·오류·운영 기록은 10일 보관 후 순차 삭제합니다. 서버의 로컬 로그 사본은 파일 용량을 기준으로 순환 교체되므로 중앙 로그와 삭제 시점이 다를 수 있습니다.
  • 서비스 간 전달 기록: 메시지·알림 등의 일회성 전달 기록은 7일을 기준으로 순차 삭제합니다. 계정·팀·채널 등의 최신 상태를 동기화하는 기록은 원본 정보의 보유기간과 삭제 처리에 따릅니다.
  • 운영팀이 관리하는 백업: 장애 복구를 위해 생성한 백업은 생성일부터 최대 14일 동안 보관한 뒤 삭제합니다. 운영 데이터에서 삭제한 정보가 기존 백업에 남아 있는 동안에는 복구 목적 외에 사용하지 않으며, 복구하는 경우 이미 접수·처리한 삭제와 동의 철회 내역을 다시 적용합니다. 외부 제공자가 관리하는 백업의 보유 조건은 제3항에 따릅니다.

삭제 대상과 보존 의무를 확인한 뒤 운영 데이터, 검색용 사본 및 서비스 간 동기화된 개인정보에 삭제를 반영합니다. 전자파일은 복구할 수 없는 방법으로 삭제하고, 출력물이 있는 경우 분쇄 또는 소각합니다. 개인정보가 삭제 대상에서 제외되어 보존되는 경우에는 해당 근거·항목·기간과 처리 결과를 요청자에게 안내합니다.

팀을 나가거나 외부 서비스 연동을 해제하는 것과 계정·기존 콘텐츠의 삭제는 구분됩니다. 계정이나 공유 콘텐츠의 개인정보 삭제를 원하는 경우 gsm.cowork@gmail.com으로 요청할 수 있습니다.

3. 정보 공유와 외부 서비스

프로필 공개는 「개인정보 보호법」 제17조제1항제1호에 따른 별도 동의를 받아 처리합니다. 제공받는 자는 로그인한 cowork 이용자이며, 목적은 사용자 검색, 협업 상대 확인과 의사소통입니다. 제공 항목은 이름, 이메일, 성별, 학년·반·번호, 전공·전문 분야, 역할, GitHub 계정, 프로필 이미지, 소개와 접속 상태 중 공개에 동의한 항목입니다. 공개를 철회하거나 계정을 삭제할 때까지 제공하며, 기본 서비스 이용을 유지하면서 공개 동의를 거부하거나 철회할 수 있습니다.

공개에 동의한 프로필은 같은 팀에 속하지 않은 이용자도 검색·조회할 수 있습니다. 협업 콘텐츠는 해당 팀·채널·저장소의 접근 권한에 따라 표시됩니다. 공개된 내용을 다른 이용자가 별도로 저장한 경우 운영자가 그 사본을 직접 회수할 수는 없으며, 부당한 이용 신고가 접수되면 필요한 조치를 합니다.

공유 계정 채널에 등록한 인증정보는 해당 채널에 접근할 수 있는 이용자가 원문을 복사할 수 있습니다. 개인 전용 계정의 비밀번호나 다른 사람에게 제공할 권한이 없는 인증정보를 등록하지 마세요. 소개 사이트의 팀원 정보와 개발 성과는 로그인하지 않은 방문자에게도 공개됩니다.

회원 정보와 협업 콘텐츠의 데이터베이스, 파일 저장소 및 회의 중계 서버는 대한민국 내 서버실의 자체 운영 서버를 사용합니다. 서버 관리팀과 운영팀 중 업무상 권한을 부여받은 담당자만 관리 목적으로 접근합니다. 소개 사이트는 Vercel에서 제공합니다. 외부 서비스와 주고받는 정보는 다음과 같습니다.

  • DataGSM: 회원 인증과 학생 정보 동기화를 위해 인증 요청과 인가 코드를 처리하고, 제1항의 회원 정보를 제공받습니다.
  • GitHub: 이용자가 연결한 계정·저장소와 이슈·Pull Request·댓글·작성자 정보를 불러오며, 연동 기능에서 작성·수정·삭제를 요청한 내용은 GitHub로 전송합니다.
  • 공유 계정의 외부 인증 제공자: GitHub, Notion, Jira(Atlassian), Google 연결 기능을 이용하면 해당 제공자에게 인증 요청·인가 코드와 요청 검증 정보를 전송하고 계정 식별자를 제공받습니다. 요청 검증 정보에는 cowork 이용자·채널 식별자, 복귀할 사이트 주소와 유효기간 등이 포함됩니다. 이용자가 비밀번호·토큰을 직접 입력하여 저장하는 방식은 외부 인증 연결과 구분됩니다.

4. 이용자의 권리

이용자는 자신의 개인정보에 대한 열람, 정정·삭제, 처리정지 및 동의 철회를 요청할 수 있습니다. 프로필에서 직접 변경할 수 없는 항목이나 계정 삭제 요청은 gsm.cowork@gmail.com으로 보내 주세요.

요청자 본인 또는 정당한 대리인인지 확인하는 데 필요한 최소한의 정보를 요청할 수 있습니다. 법정대리인이나 위임받은 사람을 통해서도 권리를 행사할 수 있습니다. 요청에는 관계 법령에서 정한 기한과 절차에 따라 조치하고, 법령상 요청을 제한할 사유가 있는 경우에는 그 사유와 처리 결과를 안내합니다.

DataGSM 등 외부 서비스가 관리하는 원본 정보는 해당 서비스에서 수정해야 할 수 있습니다. 선택정보 처리나 공개 동의를 철회하면 해당 처리를 중단하며, 외부 정보의 자동 동기화를 이유로 철회한 항목을 다시 수집·공개하지 않습니다. 만 14세 미만 아동의 개인정보를 동의에 근거하여 처리할 때는 법정대리인의 동의를 받고, 법정대리인도 아동의 개인정보에 관한 권리를 행사할 수 있습니다.

인증과 접근 권한 확인, 암호화된 통신, 계정·세션 관리 등을 통해 개인정보에 대한 무단 접근을 제한합니다. 개인정보에 접근하는 사람과 시스템의 권한은 업무에 필요한 범위로 관리합니다.

6. 브라우저 저장소와 외부 리소스

웹 서비스는 로그인 처리와 인증 상태 유지를 위해 다음 저장소를 사용합니다. 인증 쿠키는 운영 환경에서 HTTPS 연결로만 전송되며, 브라우저 스크립트에서 읽을 수 없도록 설정합니다.

  • oauth_code_verifier, oauth_state 쿠키: 로그인 요청을 검증하는 임의의 값으로, 최대 10분 동안 보관하며 로그인 콜백 처리 시 삭제합니다.
  • refresh_token 쿠키: 로그인 상태를 갱신하는 인증정보로, 발급·갱신 시점부터 30일 동안 보관하며 로그아웃 시 삭제합니다.
  • cowork_ws_token 쿠키: 실시간 연결 인증을 위한 접근 토큰으로, 발급 후 최대 30분 동안 보관하고 로그아웃 시 삭제합니다.
  • access_token 세션 저장소: 웹 API 요청에 사용하는 접근 토큰으로, 해당 탭의 세션 동안 보관하며 로그아웃하거나 인증 갱신에 실패하면 삭제합니다. 저장된 값의 존재와 서버에서의 토큰 유효 여부는 별개입니다.

브라우저의 개인정보 또는 사이트 데이터 설정에서 쿠키와 저장 정보를 삭제·차단할 수 있습니다. 이 경우 로그인 유지나 실시간 연결이 제한될 수 있습니다. 모바일 앱은 접근 토큰을 메모리에, 갱신 토큰을 기기 보안 저장소에 보관하고 로그아웃 시 삭제합니다. 데스크톱 앱은 기기의 앱 설정 저장소에 인증정보를 보관합니다.

소개 사이트는 Google Fonts의 글꼴, GitHub의 공개 프로필 이미지, Pravatar의 예시 이미지 및 저장소 언어 그래프 위젯을 불러옵니다. 외부 리소스를 요청할 때 IP 주소, 브라우저 정보와 요청 정보가 각 제공자에게 전달될 수 있습니다. 소개 사이트의 자체 코드에는 광고·분석용 쿠키나 이용 행태 추적 스크립트를 두지 않습니다.
