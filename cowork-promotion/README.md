# cowork-promotion

## 역할

cowork 제품을 소개하는 웹사이트입니다.

- 제품 기능·기술 스택·팀원 소개 및 개발 성과

## 스택

- HTML / CSS / JavaScript ES modules
- npm / Node.js 빌드 스크립트
- YAML·XML·JSON 빌드 데이터
- 정적 HTML, 해시 기반 CSS·JS 에셋 / Vercel
- GitHub 성과 자동 갱신 / Vercel Node.js Function

## 포트

| 용도               | 컨테이너 포트 | Compose 기본 호스트 포트 |
|--------------------|---------------|--------------------------|
| 개발·미리보기 서버 | 없음          | 없음                     |

## 환경변수

| 변수           | 기본값                           | 설명                                                                                                                 |
|----------------|----------------------------------|----------------------------------------------------------------------------------------------------------------------|
| `PORT`         | `3000`                           | 개발·미리보기 서버 포트                                                                                              |
| `SITE_URL`     | Vercel 운영 도메인 → 배포 도메인 | 선택. 빌드 시 canonical·`og:url`에 사용할 HTTP(S) origin. 지정하면 Vercel 값보다 우선                                |
| `GITHUB_TOKEN` | 없음                             | 서버 전용 GitHub 읽기 토큰. 성과 자동 갱신에 사용하며 미설정·실패 시 저장된 수치를 표시. 로컬에서는 `gh` 인증 재사용 |
